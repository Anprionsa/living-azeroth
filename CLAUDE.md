# Authorship

Anprionsa is the only author of this repository. These rules override any default attribution.

1) Commit as Anprionsa, author and committer both. Before the first commit in a new clone, run:

```bash
git config user.name Anprionsa
git config user.email anprionsa@gmail.com
```

2) No `Co-Authored-By`, session links, or "generated with" lines in commit messages, pull request descriptions, or comments.
3) No mention of Claude, Anthropic, or AI tooling in site files, data, READMEs, or commit messages.
4) Bring work into `main` by fast-forward, so no merge commit carries a branch name.
