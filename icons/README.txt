Talent icon manifest for the Class Absorption trees.

149 talents across 7 trees.

Each row in MANIFEST.csv gives a talent and the exact filename its icon
must have. Convert the icon to PNG, name it as the filename column says,
and drop it into this icons/ folder. Square art, 40x40 or larger.

Filenames are derived as: talent-<treeid>-<talent-name-lowercased-hyphenated>.png

Anything not supplied simply stays an empty square, so a partial set is fine.
